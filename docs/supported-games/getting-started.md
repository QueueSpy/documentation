# Supported Games

We support an abundance of multiplayer game servers for you to be able to query with QueueSpy.

If the game is relatively new we may be working on it's compatability with QueueSpy so feel free to reach out to our Support team in Discord.

Here is a list of games we currently support:

* [Ark: Survival Evolved](/supported-games/ark-survival-evolved)
* [DayZ](/supported-games/dayz)
* [Hell Let Loose](/supported-games/hell-let-loose)
* [Minecraft](/supported-games/minecraft)
* [Rust](/supported-games/rust)
* [Squad](/supported-games/squad)
* [The Isle](/supported-games/the-isle)
