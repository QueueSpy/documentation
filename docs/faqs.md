# Frequently Asked Questions
We have collected the most frequently asked questions and answered them.

## Is QueueSpy free to use?
Yes, we have a free tier of QueueSpy. You'll be able to add one game server per guild. If you would like to add more than one game server to your guild you'll need to look at a paid tier (*which also comes with more frequent updates to your server information*)

## How does it work?
To put simply our query layer works like any server browser. We use the connection details you provide to request information about your server.

## How often do you query the server?
This depends what plan you have with QueueSpy.

- **Starter/Free Tier** - We query your server every 30 minutes and then update your Dicord guild every 60 minutes.
- **Plus Tier** - We query your server every 5 minutes and update your Discord guild every 10 minutes.
- **Communuity Plus** - We query your server every minute and update your Discord guild every 5 minutes.

*Updating the Discord guild every 5 minutes is as frequently as Discord's API ratelimits let us update. Anything below this will start causing ratelimiting issues.*

## I'm a game hosting provider. Can I integrate with your service?
Absolutely, we have a full REST API that can allow you to integrate our tool with your services. Please reach out to [help@queuespy.com](mailto:help@queuespy.com) for more information.
